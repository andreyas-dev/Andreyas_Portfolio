# Premium Mechatronics Engineering Portfolio

A world-class, futuristic, and highly interactive portfolio template tailored for Mechatronics, Robotics, and Embedded Systems engineers. 

## Features
- **Strictly Vanilla:** Built purely with HTML5, CSS3, and ES6 JavaScript. No frameworks. No build steps required.
- **Run Anywhere:** Just double-click `index.html` to run it in your browser.
- **Premium Interactions:**
  - Custom cursor with trailing effects.
  - Magnetic buttons that follow the mouse.
  - 3D Tilt perspective on cards.
  - Scroll-triggered reveal animations.
  - Animated data counters.
- **Dynamic Projects:** Engineering projects are loaded dynamically from a single Javascript array (`projects.js`), making it incredibly easy to maintain and scale.
- **Fully Responsive:** Adapts flawlessly from massive ultrawide monitors down to mobile devices. Touch-friendly degradations for cursor effects.

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any modern web browser.
3. That's it! 

## Editing
Please refer to the `docs/Portfolio Editing Guide.md` for step-by-step instructions on customizing the content, styling, and adding your own projects.

## Tech Stack
- HTML5
- CSS3 (Variables, Grid, Flexbox, Keyframes)
- JavaScript (ES6, IntersectionObserver, DOM Manipulation)
- Lucide Icons (via CDN)
- Google Fonts (Space Grotesk & Inter)

## Deployment
This project is deployment-ready for GitHub Pages, Netlify, Vercel, or any standard static web host. Simply upload the files and it works instantly.
